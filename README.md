## Описание проекта

`calc.cpp` — простой консольный калькулятор на C++.
Поддерживает операции `+`, `-`, `*`, `/`, `^`.

## Сборка и запуск

```
g++ calc.cpp -o calc
calc
```

Программа попросит ввести выражение, например `2 + 3`.
Ожидаемый вывод: `2 + 3 = 5`

## Изменения

- Добавлена операция возведения в степень `^` (функция `power`).
  Пример: ввод `2 ^ 10` → `2 ^ 10 = 1024`

## Требования

- Компилятор C++ (g++/MinGW, clang или Visual Studio)
- Стандарт C++11 или новее

## APB slave (папка `apb/`)

| Файл | Назначение |
|---|---|
| `apb_master.sv` | ведущее устройство APB (задачи `apb_write` / `apb_read`) |
| `apb_slave.sv`  | ведомое устройство APB с регистрами 0x0, 0x4, 0x8, 0xC |
| `tb_top.sv`     | модуль верхнего уровня (testbench) |
| `run_modelsim.do` | скрипт запуска в ModelSim |

Карта регистров (базовый адрес устройства `0x7000_0000`):

| Смещение | Регистр | Записываемое значение |
|---|---|---|
| 0x0 | `register_with_some_name` | номер в списке группы: 11 (бит 0 = 1 → в регистре `0x5555_5555`, бит 0 = 0 → `0xAAAA_AAAA`) |
| 0x4 | `reg_date` | дата 16.07.2004 → `0x1607_2004` |
| 0x8 | `reg_surname` | "Tokm" → `0x546F_6B6D` |
| 0xC | `reg_name` | "Nade" → `0x4E61_6465` |

Запуск моделирования:

```
cd apb
do run_modelsim.do   # в консоли ModelSim
```

При успешной проверке в конце выводится `TEST PASSED`.
