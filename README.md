## Описание проекта

`calc.cpp` — простой консольный калькулятор на C++.
Поддерживает операции `+`, `-`, `*`, `/`, `^`.

## Сборка и запуск

```
g++ calc.cpp -o calc
calc
```

Программа попросит ввести выражение, например `2 + 3`.
Ожидаемый вывод: `2 + 3 = 5`

## Изменения

- Добавлена операция возведения в степень `^` (функция `power`).
  Пример: ввод `2 ^ 10` → `2 ^ 10 = 1024`
## Требования

- Компилятор C++ (g++/MinGW, clang или Visual Studio)
- Стандарт C++11 или новее
